# Feature-gap verdict — full research sweep, 4 agents — 2026-08-23

You asked: anything researched-but-unbuilt that adds real value? Four
agents read the entire corpus + IDEA-BANK against the built stack.
**Verdict: the gap is interaction depth + two flagships + measurement —
NOT more detectors.** And nothing new should start before the built
stack gets its first live test.

## Where multiple agents converged (the signal)

| Feature | Agents | Effort | Why |
|---|---|---|---|
| **Tap-to-query** (double-tap shell → VLM describes) | 2 | **S (3-5 h)** | THE demo surprise: unused on-chip silicon + built pipeline, one gesture, no hands. Also the silent-in-public path the voice research demanded |
| **Find-by-text + sign read (one OCR engine)** | 2 | M | Text = the #1-ranked BLV need; nemotron benchmarked (1.3–2.4 s, per-word boxes → beacon comes free); highest reuse of built machinery; wow 5. Headline find-by-text; label-read ships quietly (commoditized) |
| **Around-Me quadrants + "tell me more" layers** | 2 | S-M | The #1 requested interaction property in BLV studies; upgrades F9+VLM+voice at once — demo becomes a conversation |
| **Head-clearance gravity check** | 1 (its slice's #1) | M | The #1 user need (13%/mo head injuries, cane AND dog users); the IMU cal you did was the only blocker; novelty claim vs Muñoz 2025 |
| **FP/hour + intervention logging** | 2 | S-M | The anti-abandonment metric (WeWALK died of false positives); "fleet learning at N=1" story; publishable number |

## Single-agent picks worth taking (cheap)

- **Steps-not-meters** (S, ~2 h) — evidence-locked delivery change,
  touches every utterance, instant credibility with blind users.
- **Speech gate on fast head turns** (S, 1–2 h) — literature-gap
  novelty claim for the writeup.
- **Drop alarm** (S, 2 h) — crowd-pleasing empathy feature.
- **Spatialized hazard clicks** (M) — direction-carrying ticker
  (Paré 2021: blind users beat sighted controls). SUPERSEDES the mono
  ticker rather than adding a channel — the one "more audio" item that
  isn't creep. Take only if the week has room.
- **Walkable-tunnel haptics** (M) — patent-mined, free, silence-
  compatible. Next in line after the above.

## Ruthless cuts (agents' consensus, with reasons)

On-track ping (contradicts the silence-default doctrine the whole
system rests on) · pulse-count vocabulary beyond 2 patterns
(recognition falls 93→78%) · text-noticed earcon (OCR latency
contradiction; redundant with find-by-text) · empty-seat auto-pick
(COCO's worst classes; public humiliation FP) · moving-vehicle
interlock (protects an outdoor flow that doesn't exist yet) ·
trajectory-prediction (demo-fragile) · ILD sweep (no BC hardware till
Sept) · voice v2 / queue detection / describe-seating (post-deadline).

## Do-not-break rules (abandonment evidence)

False positives are the #1 return reason · silence stays the default —
new sounds are opt-in · never slow the walker · one interaction
grammar, not per-feature modes · no new hardware weight · cane owns
the ground · no fake confidence.
