# IMU creative-uses research — 2026-08-17 (Opus agent, condensed verbatim)

Fifth research stream: everything the head-mounted BNO085 can do for this
design. **Blocker: `imu_mount_cal.json` does not exist yet — run
`visualizer/imu_mount_cal.py` before building any of this.** Second gate: the
firmware enables only GRV@100 Hz; six items below are one `sh2_setSensorConfig`
call each against the vendored CEVA driver.

## The numbers everything hangs on (BNO08X datasheet v1.17 §6.7)
- GRV dynamic pitch/roll error **2.5°**, static 1.5°; mag-free heading drift
  **0.5°/min**; latency 6.6 ms @100 Hz; Gyro-Integrated RV up to 1000 Hz with
  a built-in ~28 ms head-motion predictor (1.96° error at 28 ms).
- Ground-ranging sensitivity at h≈1.6 m: **7.2 cm/deg at 2 m, 30 cm/deg at
  5 m** (grows as R²). 1° attitude error = 1.75 cm vertical per metre.
- ⇒ **drop-off/curb calls are honest to ~2.5 m, no further.** Declare it.

## Tier A — build (all host-only or one-liner firmware)
1. **Attitude-compensated ToF floor rejection** (S): each zone's true
   elevation = mount 22.5 + zone + live pitch → expected floor range
   h/sin(elev) → returns near it are GROUND. Replaces the crude row-based
   cane filter; kills false alerts when looking down.
2. **Sterile-cockpit speech gate on yaw rate** (S): suppress CAUTION above
   ~80–120°/s (measured head-turn peak 104°/s), never DIRECTIVE. **White
   space — no published ETA gates alerts on head pose** (Reyes Leiva 2021
   survey confirms the gap).
3. **Context auto-silence via on-chip classifiers** (S): PAC (in-vehicle/
   walking/still) + stability classifier already in sh2_SensorValue.h.
   Multi-second dwell before muting; instant unmute.
4. **Ground-plane ranging for camera-only detections** (S–M):
   d = h/tan(pitch+θ). Gives range in the 30° camera-only wings + past 4 m.
   Good to ~3 m.
5. **Tap-to-query** (S): SH2_TAP_DETECTOR on-chip (no aliasing at 100 Hz
   host rate). Helmet shell is a good tap substrate. 1–2 tap vocabulary max.
6. **Camera↔ToF temporal de-rotation** (M): the acknowledged correctness
   gap. YOLO-seg is ~115 ms stale → **1.39 m of misregistration at 3 m
   during a 240°/s scan**. Needs firmware timestamps on DATA:/DATAT:/Q:.
   VINS-Mono: degradation past ~6 ms uncalibrated offset.

## Tier B — high value, real effort
7. **Drop-off/stairs detection** by expected-floor differencing (M). Hines
   RA-L 2020 warning: a negative obstacle is an ABSENCE of returns — with
   4000-fill invalids you must distinguish "no floor" from "no signal."
8. **World-stabilized 2–5 s obstacle memory** (M–L, the creative flagship):
   head rotation is a free gimbal — 90° ToF pair + natural 58° sweeps ≈ 150°+
   scanned field. Rotation nearly free (0.25° drift/30 s); translation from
   step counter good ~10–30 cm over 2–3 s. "You passed a pole on your right,
   it's still beside you." Build a short memory, NOT a map (PDR is hopeless —
   see anti-list). Framing appears unpublished.
9. **Scan-coverage coaching** (M): RCT evidence scanning training works
   (de Haan 2015); target 45° eccentricity (peak collision risk, Peli 2016);
   real scan rates 6.9–14/min. Danger: nagging — rare + contextual or it's
   the first feature turned off.
10. **Head-pose prediction to hide latency** (S–M): use the chip's built-in
    predictor (don't write one). Predict the sensor-to-alert gap (~30–50 ms),
    not the full 115 ms vision latency.
11. **Fall detection** (M): head placement VALIDATED (97–98% sens at
    head/waist, Kangas 2008); real-world pooled 82%/63% — needs an alerting
    path (phone) to be worth it.
12. **Stumble/near-miss logging** (M): ear-worn F1 0.68/recall 0.86; ~400 ms
    pre-impact — too short to speak, but **every stumble is a labelled
    example the alert thresholds should have caught**. Developer gold.

## Tier C — opportunistic one-liners
13. **Step-counter landmark odometry**: ~1% count error head-worn; "about 30
    metres since the doorway" honest, "31.4 m" not. Untested at slow indoor
    speeds (head bounce weakens <1.2 m/s).
14. **Head-gaze look-to-query**: point head + tap → describe. Size targets
    ~3.5°.

## Do NOT build
- **PDR breadcrumb return-path**: head-mounted PDR is 2.3 m RMSE with heads
  held still, 9.1 m error from ONE head turn; head leads turns by ~1 s even
  eyes-closed (vestibular, untrainable). Every shipped system anchors
  (Soundscape → phone compass; NavCog → beacons). If ever: visual landmarks,
  not PDR.
- **Freeze-of-gait index**: no head-mounted literature; the 3–8 Hz band
  doesn't survive the head. The honest derivative: locomotor-band collapse +
  elevated head-turning = "hesitating/searching" state.
- **Cane-tap detection through the body**: no prior art; heel strike swamps
  it. 30-minute bench test before believing anything.

## Engineering notes
- IMU shares ToF-A's bus and POLLS (INT unwired). Event reports are free;
  high-rate raw accel would contend — that's the argument for wiring INT or
  the other bus, later.
- **Measure gyro drift with motors running before trusting anything** — the
  motors killed the mag; vibration will tax accel-based detectors. No
  published BNO085 drift-under-vibration data: an afternoon experiment and a
  publishable micro-result.
- Optional new hardware: BMP390 barometer → elevator/floor-change detection
  near-free. Low priority.
- **Novelty claim for the write-up: items 2 + 8 + 9 together sit in a
  documented literature gap** (IMUs in VI-assistive tech never model the
  user's own behaviour).
